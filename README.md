# privacy-policy

개인정보 처리방침 URL 용도 및 내용들

## 로컬 미리보기

GitHub Pages에 올리기 전에 같은 저장소 구조로 HTML을 볼 수 있습니다.

```bash
./serve.sh
```

브라우저에서 [http://localhost:8080/nback/](http://localhost:8080/nback/) 로 접속합니다.

포트를 바꾸려면:

```bash
PORT=3000 ./serve.sh
```

`nback/index.html`만 수정하면 됩니다. `privacy_policy.md`는 참고용입니다.
